# Juniper Street Café catering orders

A made-up café's catering order book (Next.js, SQLite in `data/app.db`, Better Auth). Use made-up data only.

- Runs on port 3456 (`pnpm dev`, or `pnpm build` then `pnpm start`).
- Database changes: edit `src/lib/db/schema.ts`, then `pnpm db:generate` and `pnpm db:migrate`.
- Look and feel: `DESIGN.md` and `src/app/globals.css`.
